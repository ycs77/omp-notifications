## 在 OMP 中安裝

在終端機執行以下命令，將此 repository 註冊為 Marketplace：

```bash
omp plugin marketplace add ycs77/omp-notifications
```

接著安裝基本鈴聲 plugin：

```bash
omp plugin install notification-basic@ycs77-notifications
```
